## A. Implementation

The feature adds four metadata entities and additive migration `0015`, strict
Pydantic configuration, six rule evaluators, live capability validation, safe
read-only PostgreSQL/MySQL measurements, CRUD, manual Jobs, durable scheduling,
immutable configuration snapshots, retained run/rule histories, RBAC and audit.
It reuses encrypted Connections, database adapters, the existing Job lease/retry
worker, AlertManager, incidents, notification deliveries and provider transports.

The frontend adds top-level navigation, a five-step editor (datasets, rules,
schedule, alerting, review), capability validation, list filters/actions, check
details/history/latest results and run details with measured evidence. All
comparisons remain BEST_EFFORT. Existing CDC semantics are unchanged.

47 implementation/documentation files were added or changed; their complete paths
and SHA-256 hashes are in `artifacts/data-quality/implementation-files.json`.
All pre-existing v0.3.3 implementation-file hashes remain unchanged; previously
dirty CHANGELOG/MkDocs files received additive documentation. Key files:

## E. Known limits

Only same-provider PostgreSQL/MySQL CURRENT_STATE tables are supported. Other
providers, history/event-log/SCD data, arbitrary SQL, single-dataset checks,
row-by-row reconciliation and repairs are unsupported. External table meaning
requires explicit operator attestation; known history mappings are rejected.
Naive timestamps require known timezones; ambiguous local times are inconclusive.
Full scans can be expensive; timeouts do not guarantee a physical scan limit.
Database concurrency is bounded per worker process, not by a distributed limiter.
Discovery is limited to the registered database, 1,000 tables and 500 columns.
Scope, period and predicates are shared by measured rules within a Check; Schema
Match inspects current metadata independently. Hourly retention removes at most
1,000 expired runs per sweep; existing Job/audit retention is unchanged. Removed
rules do not manufacture recovery for their previous incidents. No VERIFIED
consistency or complete-CDC-correctness guarantee is offered.
