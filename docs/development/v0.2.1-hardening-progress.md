## Dependency order còn lại

1. CDC-02: restart và offset recovery.
2. CDC-03: snapshot và schema-change safety.
3. CDC-04: WAL/binlog retention protection.
4. REL-01, REL-02, REL-03: failure recovery, retry classification và concurrency.
5. OPS-01, OPS-02, OPS-03: metadata recovery, upgrades và deployment baseline.
6. TEST-01: CI/release gate tổng hợp, full regression và release report.

Không có thay đổi API phá vỡ tương thích được dự kiến. Các test live chỉ dùng
Compose project cô lập; không được chạy vào hạ tầng dùng chung. ClueCDC tiếp tục
là control plane và không đưa CDC payload qua API.

có duplicate. Không tuyên bố exactly-once toàn cục.
