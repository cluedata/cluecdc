## Công việc còn lại

Không còn task implementation dở dang trong SEC-01 → TEST-01. Bước tiếp theo
là maintainer chạy remote workflow trên release commit cuối và operator duyệt
target environment trước promotion; không thực hiện push/tag/publish tự động.

Không có thay đổi API phá vỡ tương thích được dự kiến. Các test live chỉ dùng
Compose project hoặc Kubernetes cluster cô lập; không được chạy vào hạ tầng
dùng chung. ClueCDC tiếp tục là control plane và không đưa CDC payload qua API.
