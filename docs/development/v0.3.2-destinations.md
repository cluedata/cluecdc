# v0.3.2 destination implementation status

The v0.3.2 plan contains four warehouse destinations:

1. Google BigQuery
2. Amazon Redshift
3. ClickHouse
4. Azure Synapse Analytics

This checkout did not contain the previously planned BigQuery, Redshift, or
ClickHouse implementations. Azure Synapse work is therefore layered onto the
existing PostgreSQL/MySQL JDBC and S3 delivery architecture without claiming
that the other three warehouses are complete. The target remains v0.3.2; no
separate release, tag, publication, or main-branch merge is performed.

## Remaining implementation sequence

1. Implement a delivery worker that consumes existing pipeline topics without
   committing offsets before durable final apply.
2. Serialize deterministic batch files and manifests under the configured prefix.
3. Execute COPY into per-delivery staging tables and reconcile partial COPY results.
4. Complete append-only apply, cleanup, bounded retry, and truthful metrics.
5. Run the opt-in PostgreSQL and MySQL Azure matrices against real Dedicated SQL
   Pool resources.
6. Evaluate version/distribution-safe stateful UPDATE/DELETE/INSERT first; enable
   MERGE only if the separate preview validation matrix passes.
7. Implement BigQuery, Redshift, and ClickHouse plan items from their original
   scope, then update this matrix with evidence.
