# v0.3.2 release scope (in progress)

v0.3.2 is a single planned release containing BigQuery, Redshift, ClickHouse,
and Azure Synapse Analytics. Azure Synapse targets Dedicated SQL Pool only and
uses Azure Storage staging; Serverless SQL Pool is not advertised as a mutable
CDC destination.

This is not a release announcement. No tag or release has been created. The
[implementation status](../development/v0.3.2-destinations.md) is authoritative.
All four destinations have connection/UI support and an append-only history
runtime: ClickHouse and BigQuery use pinned self-hostable Kafka Connect sinks;
Redshift and Synapse use managed staged COPY runtimes with destination markers.

Current-state CDC is not supported for these four destinations. Real BigQuery,
Redshift, and Synapse cloud E2E, and the complete PostgreSQL/MySQL source matrix,
remain NOT RUN. Consequently this checkout is **NOT READY** for publishing as
v0.3.2 even though local implementation and regression gates pass.

## Upgrade notes

Apply Alembic migrations through revision `0013`. They extend the existing
Synapse batch states and rename its ledger table to the shared
`warehouse_batch_ledger`; existing rows are translated, not discarded. Rebuild
every Kafka Connect worker from `infrastructure/docker/connect.Dockerfile` so
the ClickHouse 1.7.0 and BigQuery 2.15.0 plugins and the ClueCDC history SMT are
present on every worker. Back up metadata and the encryption key first.
