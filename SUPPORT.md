# Support

ClueCDC Community is maintained on a best-effort basis.

- Use GitHub Discussions, when enabled, for setup and usage questions.
- Use the bug report template for reproducible defects.
- Use the feature request template for scoped proposals.
- Never post vulnerabilities or secrets publicly; follow [SECURITY.md](SECURITY.md).

Before requesting help, check the [quick start](docs/getting-started/quick-start.md),
[troubleshooting guide](docs/operations/troubleshooting.md), existing issues, and
release notes. Include versions and sanitized logs. Commercial support is not
offered by this repository and future offerings must be documented separately.
